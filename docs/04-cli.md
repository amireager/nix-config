# ۰۴ — خط فرمان: fish و ابزارها

قاعده‌ی این صفحه: **چیزی که در `man` یا `--help` هست اینجا نیست.** برای هر
ابزار فقط آن یک یا دو چیزی نوشته شده که معمولاً کسی پیدایش نمی‌کند.

## fish — چرا و چه شکلی

### مخفف‌ها به‌جای alias

مخفف (`abbr`) موقع تایپ **باز می‌شود**. `sw` می‌زنی و قبل از Enter، در خط
فرمان می‌بینی `nh os switch`.

تفاوتش با alias این است که همیشه می‌بینی چه چیزی اجرا می‌شود. یک alias
مخفی که کاری غیرمنتظره کند، بعد از شش ماه یک تله است.

| مخفف | باز می‌شود به |
| :--- | :--- |
| `sw` `tst` `bld` | `nh os switch` / `test` / `build` |
| `nrs` `nrt` `nrb` | همان سه، نام دوم |
| `nrf` | `sudo nixos-rebuild switch --flake …` |
| `gs` `ga` `gc` | `git status` / `add` / `commit -m` |
| `gco` `gcb` `gsw` | `git checkout` / `-b` / `switch` |
| `gp` `gpl` | `git push` / `git pull --rebase` |
| `n` | `nvim` |
| `myip` | `curl ip.me` |
| `fj` `fjx` | firejail سریع (نسخه‌ی کامل: [۰۸](08-sandbox.md)) |

### alias‌های واقعی

این‌ها جایگزینی‌اند، نه اختصار:

| دستور | واقعاً چه اجرا می‌شود |
| :--- | :--- |
| `ls` `ll` `la` | `eza` با آیکن و وضعیت git |
| `lt` / `tree` | درخت با عمق ۲ / کامل |
| `cat` | `bat --style=plain` |
| `top` | `btop` |

## توابع خودنوشته

اینجا چیزهایی است که در هیچ `man` ای نیست چون خودمان نوشتیم.

### `nix_proxy` — مهم‌ترین تابع این سیستم

```sh
nix_proxy 1819       # دانلودهای nix-daemon از پروکسی
nix_proxy off
```

**چرا لازم است:** `nix-daemon` یک سرویس systemd جداست. متغیرهای محیطی شل
(`HTTP_PROXY` و بقیه) روی آن **هیچ اثری ندارند**. پس یک پروکسی که در ترمینال
کار می‌کند، `nix build` را عوض نمی‌کند.

این تابع یک drop-in در `/run/systemd/system/nix-daemon.service.d/` می‌نویسد
و سرویس را ریستارت می‌کند. چون در `/run` است، با ریست پاک می‌شود — عمدی، تا
پروکسی موقت دائمی نشود.

کاربرد اصلی: پلاگین‌هایی که از `codeberg.org` می‌آیند. یک بار پشت پروکسی
build کن، بعد در store هستند. → [۰۹ باید و نباید](09-rules.md)

### `proxy_on` / `proxy_off` — فقط همین شل

```sh
proxy_on          # پیش فرض 1819
proxy_on 8080
proxy_off
```

فقط روی ترمینال فعلی. تب دیگر تحت تأثیر نیست — که همان چیزی است که موقع
دیباگ می‌خواهی.

### `px` — یک دستور از proxychains

```sh
px curl https://example.com
```

برای برنامه‌هایی که `HTTP_PROXY` را نادیده می‌گیرند. اگر `PROXY_PORT` ست
باشد، کانفیگ proxychains را موقتاً با همان پورت بازنویسی می‌کند — یعنی پورت
hardcode شده در `/etc/proxychains.conf` را دور می‌زند.

### `extract` — هر آرشیوی

```sh
extract file.tar.gz
extract file.7z
```

به‌جای یادآوری `tar -xzf` در برابر `tar -xjf` در برابر `unzip`.

### `mkcd`

```sh
mkcd newproject      # mkdir -p و cd با هم
```

## پرامپت starship

هر بخش فقط وقتی ظاهر می‌شود که معنا داشته باشد:

| نشانه | یعنی چه |
| :--- | :--- |
| `❄️` | داخل یک devShell هستی |
| `⇡۱` | یک کامیت push نشده |
| `󰍉NOTFOUND` | دستور قبلی exit 127 داد — پیدا نشد |
| `✘` | دستور قبلی شکست خورد |
| `󱑈 1s` | دستور قبلی بیش از ۱.۵ ثانیه طول کشید |

`cmd_duration` روی ۱۵۰۰ میلی‌ثانیه تنظیم است تا دستورهای عادی ساکت بمانند.

`command_timeout` روی ۱۰۰۰ است نه ۵۰۰ — چون `git status` روی مخزن بزرگ در
اولین اجرا کندتر از آن است و پرامپت اخطار می‌داد.

## ابزارهای دائمی

این‌ها همیشه در PATH‌اند. فقط نکته‌های کم‌دیده‌شده:

### فایل و جستجو

| ابزار | آنچه معمولاً نمی‌دانند |
| :--- | :--- |
| `eza` | `--git` وضعیت گیت هر فایل را ستون می‌کند |
| `fd` | پیش‌فرض `.gitignore` را رعایت می‌کند — `-I` برای نادیده گرفتنش |
| `rg` | همین‌طور. `rg -uu` یعنی «واقعاً همه‌چیز» |
| **`rga`** | همان ripgrep ولی **داخل PDF، zip، sqlite، docx** هم می‌گردد |
| `sd` | جایگزین `sed` برای جایگزینی — نیازی به escape کردن ندارد |
| `trash-cli` | `trash file` به‌جای `rm` — قابل برگشت |
| `dust` | `du` تصویری و مرتب‌شده |
| `duf` | `df` خوانا |

`rga` کمتر شناخته‌شده‌ترین ابزار مفید این فهرست است: دنبال یک عبارت در صد تا
PDF گشتن، یک دستور است.

### داده

| ابزار | نکته |
| :--- | :--- |
| `jq` | JSON |
| `yq-go` | همان برای YAML |
| `delta` | صفحه‌بند رنگی `git diff` — در `git.nix` وصل شده |

### شبکه

| ابزار | نکته |
| :--- | :--- |
| `xh` | جایگزین مدرن `curl` برای کار روزمره — `xh POST url k=v` |
| `aria2` | دانلود چندنخی، HTTP و تورنت — برای اتصال ضعیف |
| `doggo` | DNS با پشتیبانی DoH/DoT |
| `mtr` | traceroute + ping زنده، برای دیدن اینکه کجا قطع می‌شود |
| `gping` | ping با نمودار |
| `vnstat` | تاریخچه‌ی مصرف — چقدر این ماه رفت |
| `librespeed-cli` | تست سرعت بدون Ookla |

### کمکی

| ابزار | نکته |
| :--- | :--- |
| `tlrc` | `tldr` — مثال‌های کاربردی به‌جای man کامل |
| `navi` | برگه‌تقلب تعاملی |
| `glow` | نمایش markdown در ترمینال |
| `gum` | ساخت منو و prompt در اسکریپت‌های خودت |
| `just` | جایگزین ساده‌ی `make` برای دستورهای پروژه |
| `yazi` (`y`) | مدیر فایل — `y` وارد پوشه‌ی آخرش می‌شود، این تفاوت مهم است |
| `zoxide` (`z`) | `z proj` به پوشه‌ای که قبلاً رفته‌ای می‌پرد |

## `dev cli` — ابزارهای تحلیل سنگین

این‌ها دائمی نیستند چون هفته‌ای یک بار لازم می‌شوند:

```sh
dev cli
```

### جستجو و بازنویسی ساختاری

| ابزار | کار |
| :--- | :--- |
| **`ast-grep`** | جستجو بر اساس **ساختار کد**، نه متن |
| `difftastic` (`difft`) | diff که نحو را می‌فهمد |

`ast-grep` تفاوت واقعی دارد: `ast-grep -p 'console.log($$$)'` هر فراخوانی را
پیدا می‌کند، فارغ از فاصله و شکست خط. با `grep` این کار عملاً نشدنی است.

`difft` جابه‌جایی یک تابع را «جابه‌جایی» می‌بیند نه «حذف + اضافه».

### اندازه‌گیری

| ابزار | کار |
| :--- | :--- |
| `hyperfine` | بنچمارک با آمار — چند بار اجرا، میانگین، انحراف |
| `tokei` | آمار خطوط کد |
| `watchexec` | با تغییر فایل، دستور را اجرا کن |

`hyperfine 'cmd-a' 'cmd-b'` مستقیم مقایسه می‌کند. تنها راه درست برای گفتن
«این سریع‌تر است».

### JSON و لاگ

| ابزار | کار |
| :--- | :--- |
| `fx` | کاوشگر تعاملی JSON |
| `jless` | صفحه‌بند JSON با تاکردن |
| **`jc`** | خروجی هر دستور معمولی را به JSON تبدیل می‌کند |
| `dasel` | مثل jq ولی برای JSON و YAML و TOML و XML |
| `tailspin` | لاگ را رنگی می‌کند بدون اینکه کانفیگ بخواهد |

`jc` ترفند کم‌دیده‌شده است: `dig example.com | jc --dig | jq` — خروجی متنی
یک ابزار قدیمی، ناگهان قابل query می‌شود.

### پردازه و شبکه

| ابزار | کار |
| :--- | :--- |
| `procs` | `ps` با درخت و فیلتر |
| `bandwhich` | مصرف پهنای باند **به تفکیک پردازه**، زنده |
| `pueue` | صف کار پس‌زمینه — دانلود طولانی را بسپار و برو |

`bandwhich` جواب «کدام برنامه دارد اینترنت را می‌خورد» را می‌دهد.

### بقیه

| ابزار | کار |
| :--- | :--- |
| `hexyl` | نمایشگر hex رنگی |
| `grex` | از چند مثال، regex بساز |
| `erdtree` | درخت + تحلیل حجم |
| `gh-dash` | داشبورد PR و issue گیت‌هاب |
| `rclone` | همگام‌سازی با فضای ابری |
| `magic-wormhole` | انتقال امن فایل نقطه‌به‌نقطه |

## git

کانفیگ در `modules/home/cli/git.nix`:

- **`delta`** به‌عنوان صفحه‌بند: diff رنگی با شماره خط و حالت دوستونه

## tmux و zellij

هر دو هستند. `tmux` برای session پایدار روی سرور، `zellij` برای کار محلی —
چون کلیدهایش را روی صفحه نشان می‌دهد و لازم نیست حفظشان کنی.
