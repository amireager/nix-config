# ⌨️ مرجع کامل و سریع کلیدهای میانبر

این صفحه کارت مرجع سریع تمام کلیدهای میانبر دسکتاپ، ادیتور Neovim، خط فرمان و ابزارهای سیستم است.

* **`Mod`:** کلید Super (Windows)
* **`<leader>`:** کلید Space

---

## 🖥️ دسکتاپ گرافیکی — Niri

### ناوبری و جابه‌جایی ستون‌ها
| کلید | عملکرد |
| :--- | :--- |
| **`Mod + H` / `Mod + L`** | حرکت فوکوس به ستون چپ / راست |
| **`Mod + J` / `Mod + K`** | حرکت فوکوس بین پنجره‌های داخل یک ستون (پایین / بالا) |
| **`Mod + Shift + H` / `L`** | جابه‌جا کردن فیزیکی ستون به چپ / راست |
| **`Mod + Shift + J` / `K`** | جابه‌جا کردن پنجره به بالا / پایین داخل ستون |
| **`Mod + C`** | وسط‌چین کردن ستون جاری در صفحه |
| **`Mod + Q`** | بستن پنجره جاری |
| **`Mod + T`** | تبدیل پنجره به حالت شناور (Floating) |
| **`Mod + F`** | تمام صفحه کردن پنجره (Fullscreen) |
| **`Mod + Shift + E`** | خروج از دسکتاپ |

### اجرای برنامه‌ها و ابزارها
| کلید | عملکرد |
| :--- | :--- |
| **`Mod + Return`** | باز کردن ترمینال Kitty |
| **`Mod + D`** | باز کردن لانچر برنامه‌ها (Fuzzel) |
| **`Mod + B`** | باز کردن مرورگر Zen Browser |
| **`Mod + E`** | باز کردن فایل‌منیجر گرافیکی Thunar |
| **`Mod + V`** | تاریخچه کلیپ‌بورد (Cliphist) |
| **`Mod + L` (با Noctalia)** | قفل کردن فوری صفحه |

| **`<leader>uN`** | تگل پاپ‌آپ‌های نوتیفیکیشن |

| **`<leader>uf`** | تگل فرمت خودکار برای فایل/بافر جاری |
| **`<leader>uF`** | تگل فرمت خودکار به صورت سراسری |
| **`<leader>um`** | تگل رندر زنده مارک‌داون |
| **`<leader>ub`** | تگل نمایش نویسنده خط در گیت (Git Blame) |
| **`<leader>ug`** | تگل نمایش خطوط حذف‌شده گیت |
| **`<leader>ul`** | تگل شماره خطوط نسبی / مطلق |
| **`<leader>uW`** | تگل شکست خطوط طولانی (Word Wrap) |
| **`<leader>uS`** | تگل غلط‌یاب املایی (Spell Check) |
| **`<leader>ux`** | تگل سربرگ تابع جاری (Treesitter Context) |

## ⚡ خط فرمان و شل‌ها

| دستور | عملکرد |
| :--- | :--- |
| **`dev`** | نمایش فوری محیط‌ها بدون Flake evaluation |
| **`dev -i`** | انتخاب تعاملی محیط با FZF |
| **`dev <name>`** | ورود به محیط توسعه لحظه‌ای (`agent`, `ai`, `python`, ...) |
| **`dev --shell bash <name>`** | انتخاب Fish، Bash، Zsh یا shell جاری برای ورود تعاملی |
| **`dev --dry-run <name> ...`** | نمایش Flake، root و command نهایی بدون evaluation یا اجرا |
| **`dev -w <name>`** | evaluation صریح و نمایش بسته‌های محیط |
| **`dev --keep <name>`** | refresh کردن GC-root واقعی بدون ورود |
| **`dev --no-keep <name> ...`** | اجرا بدون ایجاد یا refresh کردن root |
| **`dev --roots`** | نمایش rootهای kept، broken، legacy و orphan |
| **`dev --prune`** | پاک‌سازی rootهای قدیمی، شکسته و orphan با تأیید |
| **`dev --unkeep <name>`** | حذف حفاظت GC یک محیط یا root orphan |
| **`dev -v / --verbose`** | نمایش جزئیات عملیات Nix و GC-root |
| **`box`** | ورود به `.box/work → /work` با Home ایزوله |
| **`box --dry-run <cmd>`** | نمایش Plan بدون ساخت فایل یا اجرای process |
| **`box --secure <cmd>`** | environment پاک و mountهای محدودتر؛ شبکه فعال می‌ماند |
| **`box --net none <cmd>`** | اجرای بدون شبکه |
| **`box --status`** | نمایش وضعیت و حجم storage محلی Box |
| **`box --inspect <cmd>`** | trace مختصر دسترسی target به مسیرهای کاربر و workspace |
| **`box --inspect-all <cmd>`** | trace کامل و verbose دسترسی فایل‌های target |
| **`box -e <cmd>`** | Home، tmp و work کاملاً موقت |
| **`box --mem 4G <cmd>`** | اجرای دستور با محدودیت ۴ گیگابایت رم |
| **`proxy_on [port]`** | فعال‌سازی پروکسی در تب جاری ترمینال |
| **`nix_proxy [port]`** | فعال‌سازی پروکسی برای بیلد و دانلودهای NixOS |
| **`sw`** | ساخت و فعال‌سازی نسل جدید سیستم‌عامل |
| **`nh clean all --keep 5`** | پاک‌سازی نسل‌های قدیمی و آزادسازی حافظه دیسک |
