# ۰۵ — دسکتاپ

## چرا niri و نه یک tiling معمولی

در i3 یا sway، وقتی پنجره‌ی چهارم را باز می‌کنی، هر سه پنجره‌ی قبلی کوچک
می‌شوند تا جا باز شود. فضا ثابت است و هرچه بیشتر باز کنی، همه تنگ‌تر می‌شوند.

`niri` افقی اسکرول می‌شود. پنجره‌ها در **ستون**‌هایی کنار هم می‌نشینند و
صفحه یک پنجره‌ی متحرک روی یک نوار بی‌پایان است. پنجره‌ی چهارم را باز می‌کنی،
بقیه سر جایشان می‌مانند و صفحه به سمت آن حرکت می‌کند.

نتیجه‌ی عملی: هیچ‌وقت مجبور نیستی تصمیم بگیری چه چیزی را ببندی.

**ستون** واحد اصلی است: یک ستون می‌تواند یک پنجره داشته باشد یا چند پنجره‌ی
روی هم.

### پنج ابزار خودنوشته

این‌ها اسکریپت‌اند، نه پکیج:

| دستور | کلید | کار |
| :--- | :--- | :--- |
| `fuzzel-wifi` | `Mod+N` | انتخاب و اتصال وای‌فای از منو |
| `fuzzel-calc` | `Mod+Alt+C` | ماشین‌حساب — تایپ کن، جواب را کپی کن |
| `capture-region-clipboard` | `Mod+Ctrl+P` | ناحیه را مستقیم به کلیپ‌بورد |

`fuzzel-wifi` جایگزین باز کردن یک پنجره‌ی تنظیمات است: `Mod+N`، نام شبکه را
تایپ کن، Enter.

## ظاهر

```
gaps                  12 پیکسل
default-column-width  نصف صفحه
focus-ring            ۱ پیکسل، آبی نیمه شفاف #89b4fa88
border                ۲ پیکسل
background            شفاف
```

انیمیشن‌ها فنری‌اند نه خطی:

```
workspace-switch          spring، damping 0.85، stiffness 1000
horizontal-view-movement  spring، damping 0.85، stiffness 800
window-open               200ms، ease-out-expo
window-close              150ms، ease-out-quad
```

`damping-ratio 0.85` یعنی کمی کمتر از حالت بحرانی — حرکت زنده به نظر می‌رسد
بدون اینکه بپرد و برگردد.

# کلیدها

`Mod` کلید Super است.

## حرکت

| کلید | کار |
| :--- | :--- |
| `Mod+H` `Mod+L` | ستون چپ / راست |
| `Mod+J` `Mod+K` | پنجره‌ی پایین / بالا **درون ستون** |
| `Mod+←→↑↓` | همان، با جهت‌نما |

تفاوت `H`/`L` با `J`/`K` نکته‌ی اصلی niri است: افقی بین ستون‌ها، عمودی داخل
یک ستون.

## جابه‌جا کردن

| کلید | کار |
| :--- | :--- |
| `Mod+Shift+H` `Mod+Shift+L` | ستون را چپ / راست ببر |
| `Mod+Shift+J` `Mod+Shift+K` | پنجره را پایین / بالا ببر |
| `Mod+Ctrl+←→↑↓` | همان، با جهت‌نما |

## ستون‌سازی — قلب niri

| کلید | کار |
| :--- | :--- |
| `Mod+W` | پنجره‌ی بعدی را **بکش داخل** این ستون |
| `Mod+Period` | پنجره‌ی فعلی را **بیرون بینداز** |
| `Mod+Shift+W` | همان بیرون انداختن |
| `Mod+G` | ستون را به‌جای روی‌هم، **تب‌دار** نشان بده |

الگوی معمول: ترمینال و ادیتور را در یک ستون بگذار (`Mod+W`)، بعد `Mod+G` تا
تب شوند و هرکدام تمام ارتفاع را بگیرد.

## اندازه

| کلید | کار |
| :--- | :--- |
| `Mod+R` | چرخش بین عرض‌های از پیش تعیین‌شده |
| `Mod+Minus` `Mod+Equal` | ۱۰٪ کمتر / بیشتر |
| `Mod+F` | بیشینه کردن ستون |
| `Mod+Shift+F` | تمام‌صفحه |
| `Mod+Ctrl+F` | تمام‌صفحه‌ی پنجره‌ای |
| `Mod+C` | ستون را وسط بیاور |
| `Mod+T` | شناور کن |

`Mod+R` سریع‌ترین راه است — سه چهار عرض متداول را می‌چرخد.

## فضاهای کاری

| کلید | کار |
| :--- | :--- |
| `Mod+1` … `Mod+5` | رفتن |
| `Mod+Shift+1` … `5` | ستون را ببر آنجا |
| `Mod+Tab` | نمای کلی |
| `Mod+Shift+Tab` | فضای قبلی |
| `Mod+Wheel` | بالا / پایین بین فضاها |

## اجرا

| کلید | کار |
| :--- | :--- |

| `Mod+Return` | ترمینال |

| کلید | کار |
| :--- | :--- |
| `Mod+Q` | بستن پنجره |
| `Mod+S` | مرکز کنترل |
| `Mod+Comma` | تنظیمات |
