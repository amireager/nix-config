# ۰۸ — سندباکس: `box` و `audit`

دو ابزار، دو کار متضاد و عمداً جدا:

| | کار | زمان |
| :--- | :--- | :--- |
| `box` | «این را اجرا کن، ولی نگذار به سیستمم دست بزند» | حین اجرا |
| `audit` | «این چیز سالم است؟ سیستم من سالم است؟» | ایستا، فقط خواندن |

هر دو خودنوشته‌اند و بزرگ‌ترین قابلیت‌های امنیتی این مخزن هستند.

---

## چرا `box` ساخته شد؟

سه مسئله‌ی حیاتی که یک مکانیزم هر سه را حل می‌کند:

**۱. امنیت و حفاظت از کلیدها:** یک پکیج npm یا یک agent که سورسش را نخوانده‌اید، نمی‌تواند `~/.ssh` و `~/.aws` و توکن‌های شما را بخواند.

**۲. تمیزی سیستم و ایزولاسیون محلی:** پکیج‌های نصب‌شده با `npm -g`, `pip`, `cargo` و `curl | bash` درون پوشه `.box/home/` همان پروژه ذخیره می‌شوند و سیستم اصلی را دست‌نخورده باقی می‌گذارند.

**۳. پنهان‌سازی هویت و مسیرها (Path Masking):** پوشه کاربری واقعی شما (`/home/amir/projects/...`) کاملاً مخفی است؛ پروژه در مسیر خنثی `/work` و نام کاربر به `dev` در `/home/dev` نگاشت می‌شود.

---

## ساختار و دستورات جدید `box`

رابط کاربری `box` کاملاً یکپارچه و به صورت مستقیم بر پایه فلگ‌هاست:

```sh
box [FLAGS] [COMMAND [ARGS...]]
```

### حالت‌های پرکاربرد:

| دستور / فلگ | عملکرد | توضیح |
| :--- | :--- | :--- |
| `box` | ورود به شل تعاملی (Fish) | شل ایزوله در پوشه `/work` و خانه `/home/dev` |
| `box python app.py` | اجرای مستقیم در سندباکس | ایزولاسیون کامل با حفظ قابلیت وب‌سرور/پورت‌ها |
| `box -e <cmd>` | **حالت موقت (RAM / Ephemeral)** | استفاده از tmpfs؛ پس از خروج هیچ فایلی روی دیسک نمی‌ماند |
| `box -n <cmd>` | **قطع کامل شبکه (Zero-Net)** | تست کدهای مشکوک بدون کوچک‌ترین دسترسی به اینترنت |
| `box -g <cmd>` | **شتاب‌دهنده کارت گرافیک (GPU)** | پاس دادن Nvidia GTX 1650 و درایورهای CUDA به سندباکس |
| `box -P 1819 <cmd>` | **پروکسی اجباری** | هدایت خودکار تمام ترافیک وب به پورت پروکسی محلی |
| `box -s ~/dl <cmd>` | **اشتراک پوشه خارجی** | ماونت پوشه در مسیر `/shared` داخل سندباکس |
| `box --clean` | **پاک‌سازی داده‌ها** | حذف کامل پوشه محلی `.box` در پروژه جاری |
| `box --inspect <cmd>` | **ردگیری با strace** | ثبت گزارش تمام مسیرهای هارد که برنامه صدا زده است |

---

## پورت‌های خروجی و وب‌سرورها (Web UIs & Local Ports)

در حالت عادی (بدون `-n`)، شبکه به اشتراک گذاشته می‌شود (`--share-net`). این یعنی:
* سرورهای توسعه (Vite, Next.js, FastAPI, Flask, Go) که روی پورت‌هایی مثل `3000`, `8080`, `5000` ران می‌شوند، **مستقیماً در مرورگر سیستم اصلی در دسترس‌اند**.
* هیچ اختلالی در اتصال به Web UIها یا پروکسی‌های محلی ایجاد نمی‌شود.

---

## نصب پکیج داخل جعبه (`npm -g`, `pip`, `curl | bash`)

درون `box` متغیرهای زیر ست شده‌اند:
* `npm_config_prefix=/home/dev/.npm-global`
* `PIP_PREFIX=/home/dev/.local`
* `CARGO_HOME=/home/dev/.cargo`
* `GOPATH=/home/dev/go`

تمام باینری‌های نصب‌شده در صدر `$PATH` قرار دارند و به لطف اتصال `nix-ld`، باینری‌های دانلودی بدون خطای `file not found` اجرا می‌شوند.

## `audit` — بازرسی سیستم و ریپازیتوری

مکمل `box` برای تست و اسکن ایستا:

```sh
dev audit

audit-all         # اسکن همزمان مخزن، سکرت‌ها، lockfileها و سیستم
audit-repo        # اسکن سکرت‌ها (gitleaks) و آسیب‌پذیری پکیج‌ها (osv-scanner)
audit-system      # اسکن CVEهای closure سیستم (vulnix)
```
